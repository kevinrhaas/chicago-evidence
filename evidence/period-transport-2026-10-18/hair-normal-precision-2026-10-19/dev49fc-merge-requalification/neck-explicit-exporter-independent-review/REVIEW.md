## Source findings

The parameter path requires an explicit Python list of exactly 24 finite numeric nonboolean entries, each strictly positive and at most 0.5. There is no default vector, retry loop, search, or automatic executable entry point. Parameter evaluation follows hash/ownership checks. Displacement is additionally bounded by each original final neck-column length after float32 conversion. The older pure proposed_band helper allows up to 1, but this wrapper calls the stricter explicit_parameters first.

Source guards identify material-0 continuous_body_neck range 0..240, actual coat/skin0/root+head names, pinned source ownership/remaps, retained neck prefix, 96 unique oriented source triangles in strips 7 and 8, and expected bound weights. Position writes are only 192..215. Normal writes are only 168..215. Portal 216..239 and producer head portal/band 1025..1072 remain outside both write sets. Readback sparse checks across every mesh attribute would reject changes to all 48 head vectors and all other protected position/normal/joint/weight rows. No broad spatial alias is introduced. All original indices are compared after encoding. No actual feasibility is established by these source observations.

## Required guard corrections before a future trial

1. Readback must equal the intended generated arrays, not merely have edits inside the allowed rows. Current sparse_proof permits incorrect serialization anywhere within 192..215 POSITION / 168..215 NORMAL, including unchanged old values. Require exact dtype/shape/value equality of reloaded coat POSITION to p and NORMAL to n, in addition to sparse protection. Reject introduced unused accessor substitutions as appropriate.
2. The protected document comparison removes entire accessors, bufferViews, and buffers tables. Consequently its protected rig/clips claim does not itself protect inverse-bind/animation accessor metadata or their underlying bytes. Source append/encode currently appears append-only, but make that an executable guard: original accessor and bufferView table prefixes exactly unchanged; original BIN prefix byte-for-byte unchanged; single buffer metadata unchanged except byteLength; exactly two new views/accessors with the intended refs/types/counts. Preserve every old non-mesh accessor value and metadata. This closes proof coverage rather than alleging actual corruption.
3. A future orchestration wrapper needs durable first-failure reporting. proposed_once currently raises before returning any receipt, and has no writer. Persist selected vector, input/source hashes, stage, exception and partial measurements before rethrow; use fresh output paths and never replace input/archive. Do not continue to collision, gear, poses or another vector after any failure. A rejected vector is not permission to search.
4. symbolic_plan still declares normal_changes_permitted only 192..215 and alloutside_neckband_vectors_exact. This conflicts with the intentionally wider 168..215 normal halo. Correct the new proposal's declaration and receipts explicitly; preserve the predecessor. Portal normal preservation and its possible shading discontinuity must stay disclosed.

Seven reported controls exercise sparse_rules only; they do not exercise proposed_once, append/readback, failure persistence, skinning, collision, normal continuity, or actual horse feasibility. Unit normals after float32 output should also receive an explicit finite/unit check; source normalization suggests intended behavior but is not a readback assertion. Existing area checks reject zero-area faces, not winding inversions, embedding, or shading defects.
