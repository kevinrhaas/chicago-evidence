This is a new external observer, not a rerun of the door world cell. It starts
only the same native1904 boot and records metadata. Its status/exit is ALWAYS
NONPASS, release=false and strictQualificationPassed=false, regardless of data.
Original8a packet, consumed desktop admission, receipts, source/proofs and native
site stay untouched. Separate ROOT source review and ONE original120 admission
with fresh canonical lock/original resource guard are required before execution.

The same9b6 native HTML,334 exact published runtime rows, vendor files,14106-row
fixture projection, Browser141/SwiftShader flags,1280x800 viewport/DPR1 and fresh
context are used. The exact original intended storage preset remains Light,
people/vehicles shown, morning/help-seen. No device/profile/cache override, body
replacement, APP/site write, route, camera, actor/path, time/date/detail setter,
Roam, door install/action, artificial arrival, year Jump or screenshot is called.

The inner host deadline is105s from observer start, leaving15s in original120 for
cleanup. The first Network.loadingFailed/PW requestfailed, HTTP status failure or
server/navigation failure starts a fixed5s observation window, capped by105s.
Subsequent failures never extend it. Page/console/diagnostic errors are retained
and remain NONPASS; they do not replace the declared first-request-failure window.
Metadata overflow/write failure ends collection immediately. Scope completion is
recorded BEFORE context close, so cleanup-caused failures are identifiable and
remain raw, not filtered. A final read-only native boot/preset observation has a
one-second host wait bound. No extra frame, GC or native-clock hold occurs.

Full raw CDP request/extra-info, response/extra-info, dataReceived, finish and fail
events are streamed to bounded NDJSON; Playwright failures and native console/
page errors are retained. No Network.getResponseBody, cloned response, additional
read/digest/retry or altered network/cache setting occurs. Existing HTTP source
hash validation still reads the same file stream once. For only the six failing
URLs and two peer controls, Node logs request/header/write/source-exhaust/end/
finish/close/error metadata without modifying response headers or bytes.

passive-before-app.js installs before native APP execution. Native constructors
and signals are not replaced. Prototype/function wrappers preserve descriptors,
this/args, original return values/promises and thrown error objects; each native
operation is invoked exactly once. Additional promise reactions return nothing;
the wrapper returns the ORIGINAL promise. Rejection observers mark originals
handled: exact bound FileLoader fetch/read/arrayBuffer calls already catch/adopt
these promises, but generic unhandled-rejection transparency is NOT claimed. All
observed native rejections/throws are recorded as strict forensic errors. Bound reaction callbacks retain only
primitive ID strings, not receivers/args/promises/body objects. WeakMaps/WeakSets
hold native request/response/signal/stream/reader keys; values are primitive IDs.
Strong Maps retain only ID strings and counts. Logs contain serialized primitive
metadata, never original native objects, ArrayBuffers, typed arrays or bytes.

Fetch instrumentation never reads init.signal accessors/inherited properties:
only the native Request signal when no init is supplied (the exact bound
FileLoader call form). A supplied init means effective signal is explicitly
unknown, and native fetch receives it untouched.

Observed operations: actual selected fetch response status/headers outcome,
request-signal abort reason/stack, original AbortController.abort calls after the
selected window begins, existing getReader/read EOF/byteLength/error/cancel, and
original Response.arrayBuffer settlement/byteLength. No body operation is added.
Synthetic FileLoader Responses have no URL: their arrayBuffer calls keep an own
response ID and are EXPLICITLY uncorrelated to a fetch. Controller signals may be
different from dependent Request signals; no missing dependency graph or cancel
owner is invented. Arbitrary object reasons are not inspected/coerced; native
DOMException fields and primitive reasons can be recorded without retaining them.

Limits:4096 passive metadata records,64 read settlements per reader,32 abort/
cancel stacks,50000 host trace entries and1MiB queued NDJSON. The complete next
row is serialized/count-checked against queued+next bytes BEFORE writing. Bounds/emit failures
are explicit NONPASS diagnostics, never silent truncation. Every native error is
still logged/rethrown or returned through its original promise. Diagnostic-output
failures increment an exposed primitive summary; they do not alter native calls.

Observability has a cost: extra promise reactions, signal listeners, WeakMap lookups,
stack capture, console strings and host IO may perturb timing/liveness. Prototype
function identity/toString differs even though receiver/argument/return/throw
semantics are preserved. No claim of zero measurement effect is made. ROOT and
an independent source reviewer must inspect these boundaries before any browser.
