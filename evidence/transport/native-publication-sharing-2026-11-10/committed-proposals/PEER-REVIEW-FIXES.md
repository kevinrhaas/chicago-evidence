# Independent source review and fixes

Native: the reviewer found that aliased KTX2 fetches bypassed Three FileLoader's concurrent sharing, and a rejected catalogue promise could poison normal retries. The owner restored decoder-scoped verified-fetch/transcode coalescing and evicted rejected catalogue entries. A subsequent official loadBufferView plugin handles the actual whole external image-only KTX2-buffer format, retaining logical GLB base and default parser paths. It rejects geometry/accessor, sparse, meshopt, offset/partial, stride and target misuse rather than broadening the contract. The read-only review found no further concrete blocker; real CPU38 and browser05 controls are separate recorded executions. Offline digesting has temporary encoded-buffer cost; no phone budget acceptance is inferred.

MAIN: review found seven actual transport documents with implicit heads, which the initial pointer insertion rejected; the owner added valid implicit-head handling. Rollback now preserves a preexisting same-ID catalogue and generated build metadata instead of deleting old bytes. Full-site accounting counts all regular files against exactly 1,000,000,000 bytes, retains unmatched assets/old-native copies, and checks exact-byte reuse plus logical dependency closure. Source review is not deployment or MAIN approval. No mesh, texture, LOD or quality reduction is authorized by this publication work.
