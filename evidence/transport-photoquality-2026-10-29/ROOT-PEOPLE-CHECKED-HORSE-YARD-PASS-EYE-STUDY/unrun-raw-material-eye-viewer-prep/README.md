# Prepared matched eye-normal source viewer — NOT RUN

This is a separate neutral **RAW SOURCE STUDY**, never a current published gate or photographic acceptance. It compares the exact e49 parent with the unadopted bd443df8 candidate. Neither asset is installed, no production URL is replaced, and the immutable prototype directory is not changed.

Only Node syntax parsing has run. No server, browser, WebGL render, screenshot or visible-improvement comparison has run. Wait for the root's heavy-work slot before executing.

## Relevance and limits

The actual production `standing-horses.js` applies `organic_dielectric_v1` inside private `instantiate()`, setting cloned material metalness to zero. That helper is not exported. The exported loader also owns source/sidecar qualification and cannot legitimately accept this candidate without adoption. This viewer therefore uses unchanged raw GLTFLoader materials. It does not extract/evaluate the private helper, imitate it, change sidecars, or manually adjust roughness/metalness.

Raw source metallic glints may differ from the native organic horse. A raw-study result cannot establish a native-world visible improvement. Any later adoption still needs genuine native material/pose/world comparison and new qualification. The prototype cannot thin the BODY socket/painted ring, retopologize the cheek, or add hair detail.

## Prepared protocol

- The five actual Three 0.185.1 module files and source assets have pinned SHA-256/byte counts in `VIEW-MANIFEST.json`. The current application policy source is pinned as context, not executed. The immutable prototype's generator, recipe, manifest and component/source proofs are also pinned.
- A new localhost server exposes ONLY explicitly listed study URLs. It never serves `/1835/`, the production application or a production model URL. Both models are fetched from `/study-assets/` and verified by browser SHA before actual native GLTFLoader parsing.
- Every GLTF scene root and all three skinned meshes remain present. No animation mixer, source node transform, geometry/material mutation or pose reset runs. The authored source bind/rest pose is recorded, rather than described as an arbitrary sampled standing-clip time.
- Actual eye skin streams must all be joint3/weight1. The actual source fitted eye center and directions are transformed through Three's real `applyBoneTransform()` and mesh `matrixWorld`. Head framing derives from actual skinned BODY vertices selected relative to the measured eye center/radius. No hand-invented anatomy or world placement is used.
- Four views are prepared: head profile, head oblique, eye profile, eye oblique. Each view renders both whole source scenes, using identical camera transforms and real fixed lighting. Eye distance is four measured radii; head distance is 1.8 times the measured head-box largest dimension; perspective FOV35. Oblique direction is the source-left direction with fixed .20-up/.45-forward offsets, transformed by the actual eye skin matrix.
- Neutral constants are fixed before observation: 1024-square canvas, DPR1, ACES exposure1, sRGB output, gray background, white hemisphere intensity1.2 and white directional intensities3/1. No environment map, artificial catchlight geometry, UI overlay, guide/crosshair, texture repaint or post-observation light tuning is included. This is not phone or production lighting acceptance.
- Loaded source metadata must match in actual skeleton matrices, material properties, skinned bounds, index streams and every vertex attribute except the eye normal stream. The eye normal hashes must actually differ. Genuine GL errors, page/console errors, HTTP failures, draw/memory counters and source/vendor SHA checks are recorded; counters and renderer methods are never replaced.
- Eight canvas-only PNGs have explicit `RAW-SOURCE-STUDY-<view>-<parent|candidate>.png` names. Parent/candidate camera, exposure, color output, buffer size and actual draw counts must match. Source/pins are rechecked after cleanup. All images still require personal inspection; result metadata never asserts visible improvement or adoption.
