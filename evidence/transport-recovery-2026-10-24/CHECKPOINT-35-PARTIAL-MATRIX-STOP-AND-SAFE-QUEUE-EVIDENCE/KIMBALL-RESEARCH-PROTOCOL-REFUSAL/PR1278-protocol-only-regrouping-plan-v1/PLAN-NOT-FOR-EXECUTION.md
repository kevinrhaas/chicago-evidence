- Closing1278 removes open-PR protection; after settle both tickets are offered as OPEN. Another run can legitimately claim them. The PRlap does not reserve those tickets. A race is not permission to steal. Group claims can partially succeed and push/rebase can accept different-file same-house claims, so post-push full-house revalidation is mandatory.

- The tickets workflow validates main and publishes its board branch. A local native command also rebuilds/mirrors **the APIclone's** ignored board/tickets snapshot. None may touch the frozen primary mirror.
- Checked-in Chicago lap and merge-ready code exclude DRAFT and respect a live PRlap; fleet janitor is similarly intended for open/nondraft PRs and deletes branches only after an accepted merge in the reviewed path. Closing without a delete flag should retain the head; that is still checked after the action. Unreviewed external integrations are not proven harmless by these source files.
- `pull_request` default events include `reopened`. The normal gate may rerun on the sameH747; moving-frames can run if its path filters match the then-current diff.
