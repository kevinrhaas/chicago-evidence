# Static native-owner review for optional human delivery

This is source inspection, not a generator run or a claim that the future asset gate has passed.

The delivery job begins only from a separately checked source commit. Its current local source merge still has five generated conflicts, to be resolved by canonical owners before that checked source exists. This source checkpoint cannot skip those owners.

After the later canonical generation, delivery changes only fixed human masters/exports, exact native proof copies, the human browser measurement registry, additive canonical delivery metadata, asset-license notices, and (male only) the existing Otis cost/provenance and visitor changelog fragment. No docs/LIBERTIES.md, data/sources, resident/household model record, building/terrain/scene input, threshold or cap is changed by delivery.

Current compile_liberties.py reads docs/LIBERTIES.md and declared newspaper/business/resident/structure/seating/dossier inputs. It does not consume the human export bytes, fixture.measure, asset license ledger, human instances or delivery receipt. Current compile_source_use.py Compiler.collect enumerates structures/phases, resident/household records and decisions, businesses, terrain, flora/fauna, other-scene streets/rail, exclusions, compiled liberties, loading facts and jaunt/card inputs. It does not enumerate data/humans or human binaries/license rows. No new source IDs are introduced by the delivery. Therefore the current proposal has no demonstrated Lib/SourceUse owner input change and does not widen the sealed write allowlist to their outputs or run a needless rederive tail.

Human files are not members of the building assets/manifest*.json catalogs. validate.py run_license_check checks assets/humans and authored human master paths against the exact retained LICENSES.md path text. The delivery adds explicit path/CC0-rights/actual-SHA rows for each newly installed asset while preserving earlier notices. The rights-derivation bank measures building/terrain consumed attributes and unresolved source status; none changes here, and its code explicitly does not claim all graphical families. Existing native human source/rights contracts and canonical-generation checks remain required.

Current publish.sh copies human metadata/web assets into the ignored site mirror and builds year packs. Its stamp-changelog --write-mirrors invocation writes mirrors, not tracked changelog source. It does not fold changelog.d fragments into tracked release files. Thus no additional tracked publisher-owned output is expected from this fixed asset delivery.

The complete required-reader preflight remains mandatory and may legitimately reject generated triangles/materials, registry, rights, payload cap or another dependency. Any such rejection produces no commit. If a real native owner must change a tracked output, stop and identify that owner's supported command and exact output before reviewing a bounded allowlist change; do not force-stage unrelated generated files, reset a failed output or relax thresholds. The male transition additionally proves that the entire actual Git path diff from prior female source to male definition is a subset of the fixed female delivery paths, preserving all shared authoring inputs, including inputs omitted from the small display hash manifest.
