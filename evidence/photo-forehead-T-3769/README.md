# Forehead-band correction, T-3769

The generic photographic face hull stops below the hairline. A six-texel colour fade concentrated the difference between photographic lighting and the existing skin into a visible horizontal band. The importer now blends broad lighting over wider distances while retaining fine detail in the same RGB atlases. No renderer, head fit, eye record or child proportion changes.

`rendered/comparison.png` compares the previous photographic atlas (read directly from the dev source commit) with the corrected atlas on the same heads, cameras, pose, hair and lighting. Both sides are photographic faces; the small embedded review caption describes that stage of the page, not before/after the band correction. Raw individual screenshots and full/Light/front/oblique render checks are retained, together with the sixteen-child gallery and 390x780 phone view. Pixel maxima in `render-metrics.json` are descriptive only: individual wrinkles and highlights dominate some samples, so these are not a universal band score. The controlled regression test separately verifies a smooth lighting join and preserved fine contrast.

Two actual offline writes (125.27 s and 122.73 s) reproduce all 349 outputs exactly. Only 35 existing colour atlases and two catalogs change. All 272 face/eye/hair/fit records, parents, pinned source recipes, texture dimensions and GPU budgets remain identical. A damaged child page is rejected and restored exactly. Both gated importer checks and its unit test were instrumented again and wrote nothing in the source tree. Complete default deployment checks retain 5,183 adult assignments, 2,400 child assignments and 27 protected personal assignments across all four years; face textures remain 12,582,908 bytes for the two crowd sheets and one shared nearby page.

Browser images use Chromium SwiftShader. They verify appearance and successful rendering, not real-GPU frame rate. Public source assets, fictional synthetic portraits and public CI/delivery records are archived here under the owner's explicit instruction in chicago/4d/AGENTS.md lines 417-423.
