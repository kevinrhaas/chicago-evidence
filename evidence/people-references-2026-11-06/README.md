# People reference sets (T-3417, 2026-11-06)

Period pictures that people in 4D Chicago are judged against: kevinrhaas/chicago
`chicago/4d/data/people_match/reference_sets/<set>.json` names each file here by sha256, with
its source record, the copy and crop it is, and what it shows. `tools/people_match.mjs` checks
the bytes before it lays a still beside them.

- `coachman_1904/`: a private coachman on the box, 1900s. Library of Congress: W. H. Rau
  stereograph 1902 (2010647266), Griffith & Griffith stereograph 1905 (2010647610), Edward
  Penfield drawing (2010717341). All "No known restrictions on publication."
