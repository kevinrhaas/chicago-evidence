# 1871 reference pictures sent by Kevin, 2026-11-19

Kevin sent these in the project chat ("i came across these cool pictures i hope you have these in the library and can use these as references", "these are 1871 pre fire"). The source links he gave are:
- https://stolenhistory.net/threads/chicago-pre-1871-fire-photographs-of-the-city.1309/ (a forum thread that reposts images; it doesn't hold them)
- https://nwcartographic.com/collections/chicago-prints (a print dealer selling reproductions)

Neither site holds the originals. Before any image becomes a cited source or an image-gate reference view, find the holding institution (Library of Congress, Chicago History Museum, NYPL, Newberry) and record its rights. Until then each one is a visual reference only, with rights `check_required` (AGENTS.md rule 6).
