# Actual V17/V18 software geometry comparison

This renders immutable carriage GLBs, without editing the reference photograph or generating invented geometry. The original source8 fit, crops and light directions/colors/intensities are used at fixed 1280×800 per software render panel. No per-version fitting, reframing, hidden model parts, altered GLB or source-image changes. Both models retain their original 25 meshes/seven material factors. Texture/image maps are absent and refused by this renderer; the clearcoat extension and alpha-BLEND glass are explicitly approximated.

The rasterizer uses transformed actual positions and inverse-transpose normals, original front-face winding/backface culling, perspective-correct reciprocal depth/interpolated normal/world position, deterministic opaque depthbuffer and back-to-front alpha blending. Shading is a documented hemisphere/Lambert/roughness-Phong reflection approximation with an approximate ACES curve and sRGB output. No shadow, AA, GPU quantization, Three GGX/PMREM/refraction or photographic acceptance is claimed. The original 100m floor is included without fitting.
